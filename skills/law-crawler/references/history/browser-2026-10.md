# 浏览器辅助采集

在命令行请求遇到挑战、拒绝或 TLS 错误，且需要检查正常浏览器访问时使用本流程。浏览器辅助采集记为 `browser-assisted`；只有实际取得并验证官方原件，才能计为下载成功。浏览器页面可读、适配器存在或离线导入成功，都不能证明 CLI 已能全自动下载。

## 选择可用浏览器与标签

使用所在 agent 实际可用的浏览器工具，阅读其 API 文档，只使用已公开的接口。没有浏览器工具时如实报告并保留 CLI 结果。以下 CUA 顺序是 Codex 环境的历史验证案例，Claude Code/OpenCode 不应照抄不存在的 CUA 调用，也不替代当前工具接口说明：

1. `cua.listBrowsers()` 返回已注册的浏览器清单，不保证每条请求通道都可用。首次按 `type=iab` 找到本次内置浏览器 ID，再通过 `cua.getBrowser({id: ...})` 绑定。保留有效句柄，不因新一轮、空标签或单个标签失败重选浏览器；仅实际运行时重置/明确断开后恢复句柄。数字 ID 会随会话变化，不能硬编码历史 ID。
2. 先用绑定对象的 `tabs.list()` 检查已有标签。需要新标签时，再用 `tabs.new()`、标签的 `goto()` 和 `playwright.domSnapshot()` 读取官方页面。这条独立 IAB 路径已实际成功。
3. 通用 `cua.getState()` 可能涉及不可用的后端；连续超时后不要反复调用它来判断所有浏览器是否可用。Chrome 扩展通道的实际请求曾在 30 秒后失败，但没有阻止独立 IAB 请求成功。列出浏览器或绑定成功也不能代替真实页面读取验证。
4. 新标签停留在挑战页时，检查清单中是否已有同站、已正常加载的标签，并核对 URL 和内容后复用。MK 曾出现新标签仍显示挑战、较早打开标签已自然加载目录的情况；这允许复用已正常访问的页面，不代表可以绕过验证码或访问控制。

若 URL policy 阻止读取 `data:` 错误页，不改用其他路径或接口绕过限制。只记录已观察到的导航超时、页面标题和工具错误；不能据此补写页面正文或断言远端 HTTP 状态。

### 页面读取接口超时的分层恢复

2026-10-14后续实测：IAB绑定、`tabs.list/new/close`及普通官网`goto`可用，`domSnapshot`与`screenshot`仍超时；关闭此前大PDF标签未修复读取。连接和导航成功不等于能读取或下载，不要因为元数据接口可用就不断重复截图/DOM调用。

先用已选浏览器的当前文档验证标签生命周期、一个健康对照页及一种替代读取接口；每个阶段单独调用并记录有限超时。诊断期间避免同时启动多个下载；运行时重置只重建工具句柄，不应清空用户标签、Cookie或浏览器数据。标签清单中`data:`错误页URL只保存安全摘要，不解析整段内嵌HTML或借此绕过URL策略。

若已提供的DOM与截图接口均失败，而所在agent有正常原生电脑使用工具，可改用本机浏览器的原生辅助功能/截图接口。此次用同一CUA工具的`cua.getApp('Google Chrome')`实际恢复了读取和截图，未使用外部浏览器控制脚本、修改网络或关闭安全校验。先创建自己的新标签，再正常导航；每次点击后读取新页面状态，不复用旧元素编号。其他agent应使用自己明确支持的等效接口，缺少原生通道就记录工具限制。

该方案是可用替代通道，**IAB读取接口本身未修复，根因未确定**。本机Chrome实际看到Riau/E-PPID的BPK Access Denied、DPR原件Akamai Access Denied及peraturan的ERR_CONNECTION_CLOSED。不能把“浏览器已能读取”写成“网站限制已解除”；BPK页面Country字段也不足以确定地域封锁原因。只关闭本次创建或已确认属于当前任务的标签，保留用户原有标签。

### 2026-10-15：已验证的慢读取恢复和下载对照

上段为10月14日历史结论。10月15日新实测：本地页面DOM/快照/截图可快速返回；旧、新官网标签的短调用均超时。展示IAB后官网截图通过，给标准快照40秒外层时限成功返回；随后简短DOM约9秒完成，恢复隐藏后同一DOM约30秒完成，旧BPK拒绝页快照也成功。**50秒外层调用时限的后台官网读取已通过**；这修正采集操作的超时设置，不证明宿主内部根因已定位，也不能单独认定可见性是原因。每阶段独立调用，内部 `timeoutMs` 与外层工具时限分别记录；例如DOM内部10秒、外层50秒。不要把8—12秒外层超时当成站点拒绝，或把所有读取失败直接判为浏览器断开。保持有界调用，给用户进度更新；外层50秒仍失败时记录并使用可用替代通道，不无限延长。
