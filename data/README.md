# 本地采集数据

此目录统一保存本机运行产生的资料；除本说明外，全部内容由 Git 忽略。

| 子目录                  | 用途                                                     |
| -------------------- | ------------------------------------------------------ |
| `downloads/`         | 按国家保存法规原件、派生文本、元数据和去重数据库；`.batches/` 保存批次计划、候选与历次执行结果。 |
| `reports/`           | 验证报告、采集核查和诊断证据；包含真实历史运行结果。                             |
| `tmp/`               | 临时下载文件及处理中间文件。                                         |
| `runtime/`           | 本机看板与智能体的运行状态，可按启动参数创建。                                |

源码工程使用随附默认配置时，采集输出为 `data/downloads/`。独立安装的 Skill 和显式用户配置仍按其工作区及配置解析下载路径。

旧目录可用 `python3 deploy/tools/migrate_local_data.py` 只读预览，添加 `--apply` 后迁移。工具保留原件、元数据、历史计划和报告的原始字节，仅临时备份并更新数据库的文件位置索引，操作结束后自动清理临时备份。`downloads/.relocation.json` 记录受控路径映射与原计划哈希，使支持的历史批次可在新位置读取；它不会修复原有失败、缺失输入或旧转换版本限制。

服务器的持久数据仍使用部署时明确设置的绝对路径，不随本机目录调整自动搬迁。
