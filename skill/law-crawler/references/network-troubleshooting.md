# TLS、403 与官方备用入口

用于已有适配器无法连接时的有限排查。先保存失败入口、时间与错误，再定位阻断发生在哪一层；不要把所有 `SSL` 错误都解释成证书问题。

## 判断失败层次

- DNS：比较主域名与官网已使用的 `www` 主机，记录 A/AAAA。没有 AAAA 时，强制 IPv6 没有意义。
- TCP/TLS：检查正常代理配置与单次直连的差异，可用 `curl --noproxy '*'` 做一次对照，不修改系统设置。这里的直连只绕过显式代理，不能排除系统 VPN/TUN 或透明代理。CONNECT 200 只说明代理报告接受 CONNECT，不独立证明端到端连通、目标 TLS 或 HTTP 成功。
- TLS 握手未完成且没有明确证书校验错误时，记录“握手超时/EOF”；不要记成“证书无效”。可以用保留证书校验的 TLS 1.2 对照，不使用 `-k` 或未验证 SSL context。
- HTTP 403：记录发生在列表、详情还是正文，以及响应是普通拒绝、Akamai Access Denied 还是 Cloudflare 挑战。正常 CookieJar、Referer 和浏览器访问可以帮助诊断，但不能保证解决 IP 或服务端限制。
- 用一个已通过的官方平台作对照。同客户端能访问对照站，只能缩小到目标相关故障，不能据此认定远站宕机或确定封锁原因。

诊断输出只保存请求条件摘要，不记录 Cookie、授权头或代理凭证。不同 UA、时间、路径的结果可能不同；保留每次证据，不用一次 403 覆盖此前成功的阶段。

## 官方备用入口与浏览器

从官方导航、官方说明或可核对的历史公开链接寻找同机关备用入口。API 主机有 DNS 记录不代表存在可用公开 API；需要实际接口和返回内容。JDIHN 成员源也不能代替 JDIHN 本身已跑通的证据。

优先验证列表 → 法规详情 → 原件。只有这条链实际成功，才将备用入口写入适配器并测试。单个旧 PDF 可达可以单独记录，但不算动态发现成功；新闻、摘要和检索摘要不代替法规正文。

用户已授权下载时，将已确认的官方单文件补收按[浏览器/官方文件导入](browser-workflow.md)准备manifest并生成导入批次；实际由CLI取得时显式标记`official_cli_download`，沿用格式、SHA-256、来源合并与版本保留。没有可访问详情时将 `detail_url` 留为 `null`，不要捏造详情页；身份字段只取自实际核对的 PDF 标题，字段 `source_url` 指向该官方 PDF。来源可标记 `discovery_method: direct_official_pdf`。公布、更新时间和适用地区没有核对则保留未知。

将补收及再次调用命中 `existing` 的结果单独写入运行报告，保持 `platform-status.json` 中自动发现失败的事实。`--refresh-metadata` 会跳过没有详情的来源；补收不代表列表适配已经修复，也不要把单文件 URL 硬编码成列表失败时的默认成功路径。

浏览器工具超时或连接失败属于工具不可用，不能描述成“浏览器访问官网仍被拒绝”。正常浏览器拿到页面后才记录页面状态；不要将浏览器调用成功等同于 PDF 已写入配置目录。

每种路线采用有限超时；相同失败没有新信息时停止重复请求。保留未完成平台，说明恢复所需条件：目标网络连通、官方公开入口恢复或浏览器工具恢复。不要因本机无法访问而改用来源不明的镜像、关闭证书验证或更改系统网络设置。


## 使用实验来源与历史证据

仅在明确选择`--experimental-sources`时启用JDIHN官方开发部署，按[印尼平台](platforms.md)限定主机与来源标记。成功不表示正式站恢复。

追查过去的TLS、403、IAB或备用入口行为时，按需读取[2026年10月网络观察](history/network-2026-10.md)；使用`TLS|JDIHN|DPR|BPK|2026-10-15`定位片段。重新核实当前响应，不能把历史IP、文件数量或本机工具状态代入新环境。

## 在线浏览器核验

用户要求线上执行时，在目标服务器运行实际下载和验收，不以开发机的可达性代替线上结果。必要时在服务器独立虚拟环境安装正常浏览器；保留TLS校验和sandbox，不使用隐匿参数或破解访问挑战。先用动态库检查定位明确依赖，只补必要包，不做全系统升级。用有限内存、单浏览器/单页和硬超时约束探测；若在systemd中启动失败，检查`pids.current`、`pids.max`和`pids.events`，64任务上限可能不足，证实触限后可将本次任务预算调至128，不把线程创建失败说成官网访问失败。

分别记录详情响应、原件响应、官方备用入口和实际落盘文件。详情200不代表PDF可下载；Akamai/Cloudflare的Access Denied必须维持失败，不能据此武断认定具体IP或地区封禁。截取目标服务器上实际加载的Web进度页面作为验收证据，下载中和并发上限分别核对。已完成的受控浏览器测试及时关闭进程，保留结果、截图、原件和来源证据。
