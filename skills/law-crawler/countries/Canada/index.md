# 加拿大法规与案例知识库数据源索引

按联邦法规、司法案例、开放法律数据项目分类，整理平台名称、官方 URL 及涉及的法规与法律资料类型。资料获取以免 API Key、非 PDF 格式优先。

> 整理日期：2026-10-14。本索引依据提供的清单整理，并对部分官方入口及资料范围作了核对；尚未验证批量下载或抓取。A2AJ 属于学术开放数据项目，并非政府或法院官方发布平台。

## 四、入口与范围核对说明

- **联邦 XML 资料**：开放数据门户所列资源是法律与行政法规的 XML 目录，不应直接等同于全文打包文件。司法部 [FAQ](https://laws.justice.gc.ca/eng/FAQ/) 提供单部法规 XML 获取说明及 [官方 XML 仓库](https://github.com/justicecanada/laws-lois-xml) 链接；原清单中的 `acts_regulations_xml.zip` 文件名未核实。
- **最高法院入口**：用最高法院官网及其链接的判决数据库替代 Lexum 公司主页，方便直接定位资料；本次未核实“1877 年至今全部判决”的完整性。
- **联邦法院入口**：本次浏览工具未能打开该站，保留用户提供的地址，待进一步验证可访问性、收录范围与格式。
- **A2AJ 资料定位**：作为独立开放数据来源记录，不将其描述为已核实的 CanLII 全量转存，也不预设每条记录均含法官、争议领域标签等字段。
- **采集状态**：本文件仅建立来源索引。“免 API Key、非 PDF 优先”为后续采集偏好；各平台的批量访问条件及实际文件格式尚需核实。
